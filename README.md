# go-miniblock

一个私有区块链的最小实现，纯标准库。把区块链的几个核心概念都跑通了：区块结构、哈希链、工作量证明（PoW）、交易、整链校验。配合 HTTP 接口可以提交交易、挖矿、查链、验链，适合区块链专业入门看"链到底长什么样"。

## 跑起来

```powershell
go run . -diff 3
```

`-diff` 是 PoW 难度，哈希前缀要有几个 0，越大越难挖（也越慢）。默认 3，本地秒级出块。

## 接口

```powershell
# 提交一笔交易
curl -X POST http://127.0.0.1:9200/tx `
  -H "Content-Type: application/json" `
  -d '{"from":"alice","to":"bob","amount":10}'

# 挖矿（把待打包交易打包成新块）
curl -X POST http://127.0.0.1:9200/mine

# 看整条链
curl http://127.0.0.1:9200/chain

# 看还没打包的交易
curl http://127.0.0.1:9200/pending

# 校验链有没有被篡改
curl http://127.0.0.1:9200/validate
```

## 核心概念怎么落地的

**区块**：每个块记着 index、时间戳、前一个块的哈希、自己算出来的哈希、nonce，以及这批交易的默克尔根（简化版：所有交易拼起来哈希）。

**哈希链**：每个块的 `PrevHash` 指向前一个块的哈希。改了任意一个历史块的字段，它的哈希就变，后面所有块的前驱就对不上——这就是"不可篡改"的来源。

**PoW（工作量证明）**：`mine` 不断给 nonce+1，重算哈希，直到哈希前缀有 `difficulty` 个 0 才停。难度越大要试的次数越多，这就是比特币挖矿的简化版。

**整链校验**：`Validate` 顺着链检查两件事——每个块的哈希是自洽的（用同样算法算出来等于存的），且 `PrevHash` 真的等于前一个块的哈希。任意篡改都会被抓到。

## 和真链差在哪

- 没 P2P 网络，是单机单链，节点间不广播
- 交易没签名、没余额校验，谁都能随便填 from
- 默克尔树是简化版，没做逐层哈希
- 没共识算法（没有多节点竞争出块），就一个 miner 自己挖
- 没持久化，重启链就没了
